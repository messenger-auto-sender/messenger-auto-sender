# Facebook Messenger Auto Sender

A simple **desktop automation app** that helps you send messages on **Facebook Messenger** chats one by one.  
This tool automatically selects conversations, pastes your message, and sends it — saving time when messaging multiple clients.  

⚠️ **Disclaimer:** This project is for educational and productivity purposes only.  
Automating Messenger may violate Facebook's terms of service — use at your own risk.  

---

## ✨ Features
- Automatically selects Messenger conversations  
- Pastes your pre-copied message  
- Sends messages with a single click  
- Scrolls through chat list automatically  
- Works on **Windows and macOS**  
- Lightweight and easy to run

## 🚀 How to Use
1. Make sure you have **Java JDK installed**: [Download JDK](https://www.oracle.com/java/technologies/downloads/)  
2. Download the app release from this repository.  
3. Copy the message you want to send.  
4. Open **Facebook Messenger** on your desktop.  
5. Run the app and let it automatically send your message one by one.  

---

## 💡 Example Workflow
- Copy a promotional or client message.  
- Launch the app.  
- The app automatically opens each chat, pastes, and sends your message.  
- It scrolls through chats and repeats the process until finished.
